# Original review skill sources

Current reviews load original upstream packages unchanged through GitHub Skill
Hubs. The exact source revisions, entry paths and file Git blob IDs are recorded
in `../review-upstream-lock.json`. No method bodies in this directory are used by
the runtime. The old shortened adapters have been removed.

The Apache 2.0 and CC BY-SA 4.0 license texts remain for source attribution and
historical evaluation material. Original upstream license terms continue to
apply to the gateway-imported files. Images do not automatically migrate saved
reviewers; see the application README for explicit migration and retirement.
