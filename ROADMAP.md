# Roadmap

This roadmap is intentionally short and tracks source-repository work. Environment rollout
remains in `platform-apps-deployment`.

- Complete the image cutover from the mirror in preview.
- Expand LiteLLM reporting to enumerate authorized virtual-key metadata and per-key usage without
  exposing key material.
- Add contract tests for app catalog registration and assistant popup context handoff.
- Publish versioned runtime images and document the promotion path for development and production.
